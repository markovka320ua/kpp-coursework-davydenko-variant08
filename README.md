# Курсова робота: Інформаційна система моніторингу якості води

Дисципліна «Кросплатформене програмування», варіант №8.
Студент: Давиденко Владислав Андрійович, група 201-ТН.
Національний університет «Полтавська політехніка імені Юрія Кондратюка», 2026–2027 н.р.

## Опис
Клієнт-серверна інформаційна система обліку пунктів спостереження, проб води,
вимірювань параметрів і перевірок. Для проби реалізовано чотиристанний життєвий цикл
(ЗАРЕЄСТРОВАНО → ВАЛІДОВАНО → ПРОАНАЛІЗОВАНО → АРХІВОВАНО) та інтегральний показник
I = 0,40·F1 + 0,35·F2 + 0,25·F3.

## Технології
Java 21, Maven, JavaFX, Servlet API (Apache Tomcat 9.x), MySQL, JUnit 5.

## Структура
- `database.sql` — створення бази даних `water_quality_db` з нуля та демонстраційні дані
- `server/` — серверна частина (буде додано)
- `client/` — JavaFX-клієнт; `client/sample-data/` — CSV-файли для імпорту вимірювань
- `docs/` — схема бази даних

## Підготовка бази даних
Імпортувати `database.sql` у MySQL (наприклад, через phpMyAdmin у XAMPP).
